# 02_spec — lock the smallest slice

One job: turn the inspected problem into an acceptance contract.

## Inputs
- approved inspect note
- `../../_shared/AX022_RULES.md`
- relevant architecture/security context

## Process
1. Define exact outcome and non-goals.
2. Define interfaces before implementation.
3. Define proof, failure cases, and rollback.
4. Prefer reuse of current VisionClaw pathways.

## Output
A bounded implementation specification attached to the mission.

## Human check
Confirm any changed product promise, vendor commitment, or consequential action boundary.
